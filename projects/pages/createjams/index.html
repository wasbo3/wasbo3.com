About Create Jams

I made Create Jams around the time Jams finished, the purpose: to have a minecraft server that is modded without the restrections of keeping it semi-vanilla like Jams. Create jams has most/all of the Create mods that allows players to build and automate things in minecraft, it also has a few other mods that add more content to the game.
